# GEEKS FOR GEEKS CLONE SITE

A fully responsive GeeksforGeeks-inspired blog clone built using React and Vite.  
This project includes category-based blog filtering, search functionality, dynamic routing, responsive navigation, and blog detail pages with a modern UI design.

---

## Features

- Responsive UI across all devices
- Dynamic Blog Cards
- Search Functionality
- Category Filtering
- Blog Detail Pages
- React Router Navigation
- Mobile Hamburger Menu
- Modern Responsive Navbar
- Clean Component Structure
- GitHub Footer Integration
- Deployment Ready

---

## Tech Stack

- React JS
- Vite
- React Router DOM
- CSS3
- React Icons

## Installation

Clone the repository:

```bash
git clone https://github.com/githarsh7/GEEKS-FOR-GEEKS-CLONESITE.git
```

Move into the project directory:

```bash
cd GEEKS-FOR-GEEKS-CLONESITE
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```

## Functionalities

### Search Blogs

Users can dynamically search blogs using the search bar.

### Category Filtering

Blogs are separated into categories:

- Full Stack Development
- Data Science
- Cyber Security
- Career

### Blog Details Page

Clicking a blog card opens a detailed blog page.

### Mobile Navigation

A responsive hamburger menu is automatically displayed on smaller devices.
